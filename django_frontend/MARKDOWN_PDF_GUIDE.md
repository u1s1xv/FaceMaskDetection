# Markdown转PDF功能说明

## 功能概述

系统现在支持将LLM分析结果中的Markdown格式自动转换为专业的PDF格式，提供更好的阅读体验。

## 支持的Markdown格式

### 1. 标题
- `## 主标题` - 转换为大标题样式
- `### 副标题` - 转换为小标题样式
- `#### 四级标题` - 转换为更小的标题样式

### 2. 文本格式
- `**粗体文本**` 或 `__粗体文本__` - 转换为粗体
- `*斜体文本*` 或 `_斜体文本_` - 转换为斜体
- `` `代码文本` `` - 转换为等宽字体

### 3. 列表
- `- 列表项` - 转换为项目符号列表
- `1. 编号列表项` - 转换为编号列表
- `  - 嵌套列表项` - 转换为二级列表（支持缩进）

### 4. 分隔线
- `---` 或 `***` - 转换为水平分隔线

### 5. 段落
- 空行分隔的段落会自动识别并格式化

## 转换效果

### 原始Markdown文本：
```markdown
### 口罩佩戴情况分析报告

---

#### **1. 检测结果评估**
- **数据结论**：在检测的11人中，全部正确佩戴口罩，整体合规率达100%。
- **结果可靠性分析**：
  - **模型性能**：使用的模型 `train2_20250701-101112_yolo11n_best.pt` 表现优异。
  - **置信度阈值（0.25）**：阈值较低可能导致误判风险。

---
```

### PDF中的显示效果：
- 标题使用蓝色大字体显示，四级标题使用较小字体
- 分隔线 `---` 转换为水平线
- 粗体文本以加粗形式显示
- 列表项使用项目符号格式，支持嵌套缩进
- 代码文本使用等宽字体，字号稍小
- 斜体文本以倾斜形式显示
- 保持原有的层次结构和逻辑关系

## 技术实现

1. **Markdown解析**：使用正则表达式解析常见的Markdown语法
2. **样式转换**：将Markdown元素转换为ReportLab的样式
3. **格式保持**：保持原有的层次结构和逻辑关系
4. **中文支持**：完全支持中文字体和排版

## 使用方法

1. 在LLM分析提示中使用Markdown格式
2. 获得分析结果后，点击"下载PDF报告"
3. 系统自动将Markdown格式转换为专业的PDF布局

## 注意事项

- 系统会自动处理特殊字符转义
- 支持嵌套的格式（如粗体中的斜体）
- 保持原有的段落结构和间距
- 列表项会自动缩进和对齐

## 示例输出

生成的PDF报告包含：
- 专业的标题和副标题格式
- 清晰的列表结构
- 突出的重点文本（粗体、斜体）
- 规范的代码文本显示
- 合理的段落间距和布局

这样，用户可以获得既包含丰富格式又易于阅读的专业PDF报告。
